### 🏆 Highlighted Projects

#### 🏥 Healthcare Mobile App (Graduation Project)
Flutter mobile app with ASP.NET Core backend, SQL Server DB, and a React web dashboard.
- Real-time chat via SignalR
- Video call meetings with a join-window flow
- AI chatbot integration with recommended doctor logic
- Appointment booking & cancellation flows (Doctor / Nurse / Lab)
- Full dark/light theming across the app

#### 🤖 Medical RAG Chatbot
A Python-based medical assistant chatbot using LangChain, Ollama, ChromaDB, and `mxbai-embed-large` embeddings over a bilingual (Arabic/English) disease-symptoms dataset, with specialty mapping and non-medical query guarding.

#### 💬 MediCare AI
A bilingual React-based medical chatbot prototype.

#### 🩺 MedDx AI
A diagnostic app prototype with symptom input and specialty recommendation logic.
